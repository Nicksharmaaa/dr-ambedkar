# MULTIMODAL ARCHITECTURE & ASK THIS PAGE
## Ambedkar Heritage Intelligence & Digital Preservation System — Phase 9

---

### 1. Multimodal Page Understanding & Non-Destructive Layering

For difficult, degraded, or multi-column archival pages from the Dr. B.R. Ambedkar corpus, the platform employs a dual-layer strategy:
1. **Authoritative OCR Layer**: Verbatim bounding boxes and ALTO XML transcription generated by PaddleOCR PP-OCRv5 and PP-StructureV3.
2. **Visual Intelligence Layer**: Layout reasoning and visual structural analysis performed by the Qwen3 vision-language family (`qwen/qwen3.8-27b` / `Qwen3-VL-2B`).

```
┌────────────────────────────────────────────────────────┐
│               ARCHIVAL FOLIO FACSIMILE                 │
│         (High-Resolution Scan / SVG Canvas)            │
└──────────────────────────┬─────────────────────────────┘
                           │
             ┌─────────────┴─────────────┐
             ▼                           ▼
┌─────────────────────────┐ ┌─────────────────────────┐
│       OCR LAYER         │ │      VISION AI LAYER    │
│  - Coordinate boxes     │ │  - Structural reasoning │
│  - Verbatim tokens      │ │  - Column segmentation  │
│  - Confidence scoring   │ │  - Marginalia detection │
│  - Immutable master     │ │  - Footnote recognition │
└────────────┬────────────┘ └────────────┬────────────┘
             │                           │
             └─────────────┬─────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│             OCR CONFLICT AUDITOR ENGINE                │
│  - Compares OCR tokens with visual reading             │
│  - IF DISAGREEMENT DETECTED:                           │
│      Show conflict explicitly in UI banner             │
│      DO NOT silently replace archival OCR              │
│  - Logs conflict in multimodal_page_analyses           │
└────────────────────────────────────────────────────────┘
```

#### Zero Silent Replacement Rule
Under no circumstances does multimodal vision reasoning overwrite the archival OCR text. When a conflict exists (e.g. damaged ink in 1927 paper causing OCR to misread characters), the system highlights the discrepancy in the UI:
- **OCR Reading**: Verbatim output from the preservation pipeline.
- **Vision AI Reading**: Suggested visual interpretation with confidence score.
- **Scholar Annotation**: Preserved for archival review without altering the base bitstream.

### 2. Signature Feature: Ask This Page

On every folio in the Archival Document Viewer, visitors can trigger the `[ ✨ Ask This Page ]` drawer to perform structured, grounded inquiry restricted to that specific folio:

```
[ ✨ Ask This Page ]
├── 📝 Summarize this page (2-paragraph executive synthesis of page arguments)
├── 💡 Explain this page (Pedagogical conceptual breakdown)
├── 🌐 Translate this page (Scholarly Indic translation into Hindi or Marathi)
├── 🔊 Read this page aloud (Neural Indic audio streaming)
├── 🏛️ Identify people & topics (Extract historical figures, legal cases, concepts)
└── 💬 Ask a custom question (Targeted scholar question grounded strictly in page text)
```

---

### 3. Citation Segregation & Grounding Integrity

In accordance with Phase 7 and Phase 9 evidence mandates:

#### 1. Direct Page Derivations
When an answer is formulated directly from the active folio:
```
Source: Current Page
Grounded strictly in Castes in India (Page 14)
```

#### 2. Supplementary Related Evidence
When broader corpus evidence is consulted to answer a comparative inquiry:
- Supporting evidence is presented in a separate **"Related Archive Sources"** panel.
- Under zero circumstances are external documents represented as being part of the current page.

### 4. Database Schema: `multimodal_page_analyses`

```sql
CREATE TABLE IF NOT EXISTS multimodal_page_analyses (
    id TEXT PRIMARY KEY,
    object_id TEXT NOT NULL,
    page_number INTEGER NOT NULL,
    model_name TEXT NOT NULL,
    visual_summary TEXT,
    visual_ocr_text TEXT,
    conflict_detected INTEGER DEFAULT 0,
    conflict_details TEXT,
    created_at TEXT NOT NULL,
    FOREIGN KEY (object_id) REFERENCES archival_objects(id) ON DELETE CASCADE
);
CREATE INDEX IF NOT EXISTS idx_multimodal_obj_page ON multimodal_page_analyses(object_id, page_number);
```
